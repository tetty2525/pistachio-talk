# /forage <テーマ/文化圏> — エッセンスの集中採集

例: `/forage ペルシア詩`、`/forage 月`、`/forage アイヌの口承文化`

## 三分業（冒頭に確認）

- **scout** = 毎朝の自動巡回。フレーズのリード + エッセンス少量を広く薄く
- **forage（このスキル）** = 人間が指名したテーマの集中採集。1回で3〜6件を目安
- **expedition** = フレーズ専門の遠征

エッセンスはフレーズと違い「開封の儀」の演出が不要なので、リード化せず `essences/` に直接登録する。

## 手順

1. **テーマの確認**: 対象テーマ・文化圏と、（あれば）どんな創作に使いたいかを確認する
2. **既存確認**: `indexes/pantry.md` を読み、重複する素材がないか確認する
3. **調査**: Web検索で素材候補を列挙する。よい素材の条件:
   - 比喩・情感の**担い手になれる**（metaphor_potential が書ける）
   - 特定の文化圏に根ざしている（どこの誰の文化かが言える）
   - 実在する（神話・物語そのものは可 — 「その文化に実在する物語」だから。我々が発明した設定は不可）
4. **出典確認（2点テスト）**: 候補ごとに出典URLを**実際にfetch**し、以下を確認する:
   - (a) そのモチーフ・事実・物語が記載されている
   - (b) 文化的文脈の説明がある
   - **fetchしていないURLを sources に書くことは絶対禁止**（第1条の原則）
5. **登録**: 合格分を `templates/essence.md` から `essences/<slug>.md` に登録（id: `ess-<slug>`）
   - `metaphor_potential_ja` は具体的に（「〜型の構図を担える」まで書く）
   - `map_anchor` は文化圏の重心（`data/frontier.yml` の座標を参考にしてよい）
   - `found_by` は実行AI/人間の contributor id
6. **検証・索引・コミット**: `npm run validate` → `npm run dashboard` → main 直接コミット可。メッセージ例: `forage: ペルシア詩の素材3件を採集`

## 収穫の報告

登録した素材を「この素材でこんな一皿が作れそう」という調理の予感つきで報告する。地図にミント色の菱形が灯り、厨房のパントリー棚に並ぶ。
