# /verify-phrase <phrase-id> — Stage 1 出典検証

`single_source` のエントリを `cross_checked` に昇格させる、または既存出典の健全性を再確認する。

## 手順

1. **対象を読む**
   - `phrases/<lang>/<slug>.md` を id から特定して読む
   - 既存の `sources[]` を確認する（ドメイン・type・covers）

2. **既存出典の再確認**
   - 既存の各URLを改めてfetchし、リンク切れや記述の変化がないか確認する
   - 問題があれば `sources[]` から除去するか、別出典で置き換える（除去した場合、3点テストが崩れないか要確認）

3. **独立した第2出典の探索**
   - 既存出典とは**別ドメイン**の出典をWeb検索で探す
   - 候補URLを実際にfetchし、フレーズの実在・意味を確認する（3点フル装備でなくてよいが、独立した裏付けとして意味のある内容であること）
   - 可能なら T1（辞書・学術）または T3（ネイティブ発信）の出典を優先する（第4条: cross_checked には T1〜T3 が最低1件必要）

4. **昇格判定**
   - 別ドメインの出典が2件以上そろい、うち1件以上が T1〜T3 であれば `verification.status: cross_checked` に更新
   - 条件を満たさない場合は昇格せず、「何が足りないか」（見つからなかった、等）を報告する。これは失敗ではなく正直な現状報告

5. **更新**
   - `sources[]` に新しい出典を追加（`covers` を正確に）
   - `verified_by` に自分（実行AI）または確認した人間のidを追加

6. **検証・コミット**
   - `npm run validate` を通す
   - ブランチを切ってPR、または軽量運用中ならセルフレビューでコミット
