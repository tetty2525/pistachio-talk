# 厨房の記録（レシピ帳）

料理場（Kitchen）で創作したセリフとそのレシピ。`npm run dashboard` で自動生成。

## この街のどんな薔薇より、僕は君に恋する夜鶯でいたい。

- 場面: romantic_interest / 夜の庭園を並んで歩きながら / トーン: poetic
- 素材: 薔薇と夜鶯（ゴル・オ・ボルボル）（`ess-rose-and-nightingale`）
- 調理メモ: ペルシア詩の「薔薇と夜鶯」の非対称な片思いの構図（気高く完璧な薔薇＝相手／鳴きやまず歌い続ける夜鶯＝自分）を借りつつ、直訳調にせず「街のどんな薔薇より」という比較の形に変換して口説き文句として自然な日本語にした。
- 作: hiroto, claude-code-hiroto（2026-07-18, `cre-ja-bara-yori-mo-utau`）
