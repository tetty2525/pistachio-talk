# private/ について

このディレクトリは `.gitignore` により**共有リポジトリから除外**されている（このファイル自体は例外的にコミットされる）。

実践メモ（`field-notes/`）の共有層は構造化データ（日付・相手の属性・反応など）のみで、自由記述は `note_ja` 1フィールドに限られる（第5条）。生々しい詳細を書きたい場合はここに置く。

## 規約

- 好きな構成で使ってよい。推奨は `private/field-notes/<field-note.private_ref に書いたファイル名>`
- `field-notes/*.yml` の `private_ref` フィールドは「本人の `private/` 内のファイル名」という約束事であり、他人からは解決できなくてよい（本人と本人の Claude だけが読めればよい）
- バックアップが欲しい人は、このディレクトリの中身を自分専用のプライベートGitリポジトリとして `git init` して構わない（このリポジトリの `.gitignore` で無視されているので、外側のコミットには一切影響しない）
